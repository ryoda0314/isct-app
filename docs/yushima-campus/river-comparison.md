# お茶の水橋から見る湯島キャンパスと神田川

## 橋を歩く視点

2025年3月の親柱の接写と2026年1月公開の歩道の写真を、橋上から病院を向いた3D画面と照合した。病院側に向かって右の下流側歩道を広くし、灰色の長方形の舗石を横向きに敷いた。黄色い誘導帯は欄干寄りを通る。車道との境には黒い横桟の防護柵があり、橋の中央付近には横棒から二つの笠を下げた街灯が立つ。欄干の桟、前に張り出す手すり、支柱の両脇に一つずつ付く半円形の鋳物、親柱の丸い端部と銘板をそれぞれ立体で作った。[補修後の歩道と橋梁灯の現地写真](https://note.com/kosenkyo1977/n/n921c9403039a) ・ [補修後の親柱と手すりの現地写真](https://ameblo.jp/misatohiro47626/entry-12892149003.html)

区の補修資料にある下流側歩道の拡幅量は1.5 m。既設の笠木と追加した手すりは図中でも高さが違う。桁については側面と下からの写真を使い、淡い緑の鋼板、補剛材、縁のフランジ、橋脚と桁が曲線でつながる部分、橋の奥まで並ぶ複数のフレームを作った。舗石・鋳物の大きさ、街灯の寸法、桁の断面と塗色には写真からの推定を含む。[千代田区による橋の全景と親柱（PDF）](https://www.city.chiyoda.lg.jp/documents/4200/43-ochanomizubashi-r405.pdf) ・ [区議会の補修・拡幅資料（PDF）](https://gikai-chiyoda-tokyo.jp/about/nittei/2023/files/20231208kanmachishiryou.pdf) ・ [文京区による手すりの仕様変更（PDF）](https://www.city.bunkyo.lg.jp/documents/6814/202263113738_1.pdf) ・ [補修後の橋の側面写真](https://san-tatsu.jp/articles/514460/)

## 橋から駅と川を見下ろす視点

御茶ノ水駅を設計したJR東日本建築設計の竣工写真には、川側に引っ込んだガラス面、ひさしを支える柱、細い手すりのあるテラス、植栽、その下を通る線路が重なって写る。モデルでは駅舎とホームを別の高さに置き、この間に列車が見える空間を確保した。御茶ノ水橋口には、街路側から見た駅名板、白い横長のひさしと入口の奥行きを付けている。[JR東日本建築設計「御茶ノ水駅改良」](https://www.jred.co.jp/projects/p022.html) ・ [駅前・両岸の散策写真（PDF）](https://kasukabe.genki365.net/group_186/assets/57%20%E5%BE%A1%E8%8C%B6%E3%83%8E%E6%B0%B4%E9%A7%85%E3%81%8B%E3%82%89%E6%9D%B1%E4%BA%AC%E9%83%BD%E6%B0%B4%E9%81%93%E6%AD%B4%E5%8F%B2%E9%A4%A8%E6%95%A3%E7%AD%96.pdf)

大学側の岸には低い石積みと樹木のある法面を、駅側には高い擁壁と線路が延びる平らな路盤を設けた。線路上には中央線快速の帯色、各扉の窓、台車、架線を作り、12両編成の東京寄り4・5両目に二階建て車両を組み込んだ。列車は景観用に固定している。個々の樹形、駅テラスの柱間、車両の停車位置、護岸高、水位と路盤高は近似値を使用した。[駅と川の竣工写真](https://www.jred.co.jp/projects/p022.html) ・ [JR東日本による中央線快速の車両構成（PDF）](https://www.jreast.co.jp/press/2024/hachioji/20241213_hc01.pdf)

アプリの学内マップで湯島を選び、「構内を歩く」を開くと橋上から大学を見られる。そこから右に向くと神田川・中央線と聖橋が見え、橋を南に進むと御茶ノ水橋口に着く。橋のそばの水面には、同じ3Dシーンを鏡面側のカメラで描いた橋・駅・樹冠・空の像を重ねている。撮影者の写真は照合用に参照し、舗装・水面・建築・植栽・車両にはモデルの形状、材質と手続き的な模様を使った。
