# 知と癒しの庭から見るM&Dタワーと大学病院

庭園から見上げた大学の写真では、中央のタワーに青い横連窓、折れ曲がった濃色のガラス帯、淡色の窓帯、緑がかったホワイエの順に外装が並ぶ。右手には、石張りの斜めの壁とA棟外来部の丸柱が並んで見える。この順序を保ったまま、庭園とデッキの高さから3Dを照合した。[東京科学大学の湯島・駿河台キャンパス写真](https://admissions.isct.ac.jp/ja/001/student-life-and-careers/campus-intro/yushima-surugadai)

| 照合箇所 | 写真から読み取った特徴と立体への反映 |
| --- | --- |
| タワーの研究階 | 細いサッシの窓と、青色の金属・ガラスの腰壁が交互に続く。窓、腰壁と水切りを別々の奥行きに置いた。下の暗色帯は高さに伴って手前へ傾くガラス面で作った。[大学の施設別写真「M&D Tower」](https://www.tmd.ac.jp/cmn/jdp/science_tokyo_advantages.html) |
| 庭側の低層部 | 淡色の横帯の一部に奥まった濃色の開口がある。ホワイエの外側の半透明ガラス、ガラス越しの丸柱・床端、奥の窓、入口の扉と庇を個々の立体にした。庭・周辺建物を3Dシーンから一度描き、視点に応じてガラスへの映り込みが動く。[大学の庭園写真](https://admissions.isct.ac.jp/ja/001/student-life-and-careers/campus-intro/yushima-surugadai)／[文部科学省の断面・ホワイエ写真、pp. 11–12](https://www.mext.go.jp/content/1387798_8.pdf) |
| タワーの石張りと頂部 | 斜めの壁をガラス側から見ると、細い縦窓のペア、小窓、幅広い窓が並ぶ。石張りの面を実際にくり抜き、見込み、窓台、窓で途切れる目地を設けた。屋上サインの二段の英字と左の「Science S」を立体形状で表現した。[庭園から見たタワー](https://admissions.isct.ac.jp/ja/001/student-life-and-careers/campus-intro/yushima-surugadai)／[大学のシンボルマーク](https://design-system.isct.ac.jp/ja/brand/elements/seal) |
| 正面デッキ | 駐車場屋上からM&Dタワーのホワイエへ歩行者デッキが接続する。南側の柱と庇の下に床を通し、南東端で既存の2階歩行者橋へ接続した。床の輪郭を歩行時の高さ判定にも使う。南東の入口は地上と2階の双方に設けた。[大学によるデッキの完成記録](https://www.tmd.ac.jp/news/20140110_1/)／[分子腫瘍医学分野の1階・2階入口案内](https://www.tmd.ac.jp/grad/monc/access.html) |
| A棟・B棟 | A棟の庭側には、外来部の角の丸い柱、影が入る帯窓、淡色の外壁パネル、窓の上の二段の水平ルーバーが見える。上部病棟は奥のガラス面と手前の袖壁・床版を分け、外来部との段差を残した。[大学の施設別写真「Medical Building A/B」](https://www.tmd.ac.jp/cmn/jdp/science_tokyo_advantages.html) |
| A棟のヘリポート | 屋上写真の緑の床、内側の黄色い区画線、縁に沿う金属の格子通路と灯器を確認した。立体には床を支える梁と筋かい、着陸面より一段低い点検通路も設けた。[東京科学大学病院のヘリポート写真](https://admissions.isct.ac.jp/ja/001/student-life-and-careers/campus-intro/yushima-surugadai) |

写真から実測できない窓の見込み、石材一枚の寸法、ガラスの反射率、デッキの幅は近似値である。デッキを支える柱の配置、近接写真に写らないB棟の各窓、ヘリポートの灯器間隔も同じ建物の外形と写真の比率から補った。

実装後は学内マップのWebGLシーンで庭園、M&Dタワー、A棟の地上視点と、屋上を上から見た角度を確認した。歩行者橋からタワー正面の庇までを約32 cm間隔で検査し、手すりにぶつからず同じ高さで移動できることと、隣接する地上通路との高低差をテストした。
