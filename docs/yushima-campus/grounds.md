# 湯島キャンパスの屋外空間

## 門と徒歩経路

大学の構内図で9か所の門と建物同士の位置関係を照合した。神田川の南岸からは、JR御茶ノ水駅の御茶ノ水橋口、神田川を渡るお茶の水橋の歩道、外堀通りの横断歩道を順につないだ。聖橋は外堀通りと鉄道の上を通る。東側では聖橋の上段と外堀通りの下段を結ぶ階段を別の辺として扱う。[大学の構内図](https://www.isct.ac.jp/ja/001/about/campuses-and-offices/yushima-and-surugadai)

座標列の基礎には OpenStreetMap の歩道、構内車路、歩行者デッキ、駐車場、屋上庭園、神田川護岸線、線路、駅ホーム、街路樹を用いた。地図に歩道中心線のない東側の中庭、南側小路、屋上庭園の周回路は大学の案内図および屋外写真から補った。端点は現行の建物輪郭の外に調整している。データ中の `osm-` に続く番号が元の way ID となる。正式に表示された門と道路中心線の位置には数メートルの差がある。[© OpenStreetMap contributors](https://www.openstreetmap.org/copyright) · [湯島キャンパス周辺の地物](https://www.openstreetmap.org/way/52980054)

屋外経路は各棟の前面通路、橋の歩道、庭園への連絡デッキまでを案内する。通常の病院受付へ向かう来院者に対して大学病院は、外堀通り側のC棟内からエスカレーター・エレベーターで上がる順路を案内している。そこからA棟またはM&Dタワーに続く通路へ出られる。屋内を使う経路、入構時間、受付時間は病院公式案内を参照する。[医科の入口案内](https://www.tmd.ac.jp/medhospital/about/acc.html) · [歯科の入口案内](https://www.tmd.ac.jp/dent_hospital/access/) · [大学によるM&Dタワーへの道順](https://www.tmd.ac.jp/files/topics/62458_ext_20_16.pdf)

## 外堀通りから病院までの路面

JR御茶ノ水駅からC棟まで歩くと、お茶の水橋の歩道、北詰の石の親柱、外堀通りの横断歩道、赤い舗装の前庭を順に通る。橋詰は親柱の手前で歩道が曲がり、橋上の横断歩道では縁石が低くなる。C棟前とお茶の水門前は、歩道の石畳が車道の縁まで続くようにした。車道のカーブ、車寄せの開き方、横断帯の幅は写真からの推定。舗装、白線、縁石、誘導帯は形状と手続き的な材質で作成した。[病院の入口写真と案内](https://www.tmd.ac.jp/medhospital/about/acc.html) · [地理院地図の空中写真](https://maps.gsi.go.jp/#19/35.7005/139.7639/&base=ort&ls=ort&disp=1) · [千代田区のお茶の水橋資料](https://www.city.chiyoda.lg.jp/documents/4200/43-ochanomizubashi-r405.pdf)

学内では東京都の地盤点で路面の高さを照合した。建物の庇でデータが途切れる場所は、隣接する路面とデッキの高さを使って勾配を補った。本郷門・西門・聖門では、擁壁の上の歩道と下の構内車路を別々にたどる。聖橋北詰の約5.3mの高低差は、両端に踊り場がある31段の階段として表現した。[東京都の区部点群データ](https://catalog.data.metro.tokyo.lg.jp/dataset/t000029d0000000024) · [大学による本郷門・3号館入口の写真案内](https://www.tmd.ac.jp/gradh/bi/3goukan.html)

同じ位置・方角の歩行画面で、C棟前の白線の端、門の車寄せ、外堀通り沿いの歩道を比較できる。D棟前の分岐では、歩道を横方向に20cm進んだ際のモデル上の最大高低差が2.36mから6cmに減った。橋詰とC棟前の857地点で、見えている舗装と歩行床の差は点字ブロックや白線を含めて2.5cm以内だった。[修正前後の路面を比較する](qa/road-comparison.jpg)

## 知と癒しの庭

立体駐車場は OSM way 682255318、屋上は 676718846、歩行者デッキは 676717685 と 676718845 をもとにした。大学の俯瞰写真と地上写真から、梅の花をかたどった五弁の植栽、芝地、サークル状の木質床、円形花壇に沿う木製ベンチ、照明、外周の手すりを個別の立体として作った。2018年寄贈の日時計は大学広報誌を参照し、青灰色の石の台座、銅色の円盤、三角形の指針、正面の飾り板を重ねた。庭園内の個々の花と樹木の位置、時計の正確な向き、およびデッキと構内通路の高さは推定している。[大学による屋上庭園の写真](https://www.tmd.ac.jp/kouhou/tmdu_album/parkingplace/) · [庭園・デッキの竣工記録](https://www.tmd.ac.jp/news/20140110_1/) · [日時計の写真・解説](https://www.tmd.ac.jp/files/topics/53403_ext_07_7.pdf)

庭園の徒歩視点は芝地の南側の園路から、中央の木とM&Dタワーの玄関庇を見通す位置に合わせた。大学の春の写真に写るピンクの花、花びらの内側の淡い砂利と独立した植栽、中央の丸い花壇を順に照合した。俯瞰写真と地理院の空中写真から、芝に入る四つの園路、東側の丸いデッキ、西側の三つの角形ベンチの位置も修正した。東側のデッキには板の継ぎ目、外向きのベンチ、輪状の花壇がある。草花・芝の葉・樹冠の細部は視点との距離に応じて切り替わる。花の数や樹木の枝ぶり、開花と日差しは春の掲載写真からの推定である。[大学の庭園写真](https://admissions.isct.ac.jp/cms/component/data/6322/2624a4a96454ce5167991ef2a7a603b8.webp) · [大学の庭園アルバム](https://www.tmd.ac.jp/kouhou/tmdu_album/parkingplace/) · [地理院地図の空中写真](https://maps.gsi.go.jp/#18/35.7012/139.7635/&base=ort&ls=ort&disp=1) · [同じ方角での3D歩行画面](qa/garden.png)

## 神田川と御茶ノ水駅

河川の両岸は OSM ways 286063227 と 264448302 の水際を使用した。お茶の水橋は緑色の鋼製桁、聖橋はコンクリートの中央アーチと側径間を表し、橋面、歩道、高欄、桁の下面を分けている。JR駅には線路とホーム、上屋、柱、改札側の橋上建物を置き、下流には丸ノ内線の神田川を斜めに渡る鋼桁を置いた。橋梁の細部寸法、桁下・水位、駅の屋根と線路の断面形状は地図と地形を基にした近似である。[千代田区「お茶の水橋」](https://www.city.chiyoda.lg.jp/documents/4200/43-ochanomizubashi-r405.pdf) · [土木学会「聖橋」](https://www.jsce.or.jp/branch/kanto/04_isan/h29/h29_1.html) · [文化庁「東京地下鉄丸ノ内線御茶ノ水橋梁」](https://kunishitei.bunka.go.jp/heritage/detail/101/00014748)

舗装は形状と手続き的な目地模様で、街路樹は幹、枝、立体の樹冠で描画する。門の文字はキャンバスで組版し、厚みのある門標に重ねた。門標、植栽、道路設備の細部は模式化している。資料写真は配信資産に含めていない。
