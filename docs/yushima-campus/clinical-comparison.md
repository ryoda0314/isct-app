# 湯島キャンパスのC棟前庭と2号館玄関

## 病院C棟

御茶ノ水橋から見える正面では、両端の白い袖壁と暗い縦の溝が、淡い緑白色のパネルを挟む。設計者の正面写真で縦割りを数え、モデルを40区画とした。二段の窓列にそれぞれ四組の対窓、最上部に上下二段の暗い格子を配置した。横目地は窓の上下端に合わせて高さを変えている。側面の帯窓は奥へ下げ、淡い茶色の外壁を前に出した。大学の2025年の外観写真をサインの状態と色の基準にした。[設計者による正面・斜めの竣工写真](https://k-ito.co.jp/works/detail/386)・[東京科学大学のキャンパス紹介・C棟](https://admissions.isct.ac.jp/ja/001/student-life-and-careers/campus-intro/yushima-surugadai)

低層部では、張り出した庇の裏、白い列柱、柱間の縦長の暗いガラス、下半分の細い横ルーバー、奥のガラス面を別々の位置に置いた。中央から少し東に寄る玄関の白い額縁に厚みを付け、扉を奥に下げた。東端には茶系の帯窓が四段に並ぶ。[設計者の正面写真](https://k-ito.co.jp/files/work/image1/386/1.jpg)・[病院の平面図と側面図](https://www.tmd.ac.jp/dent_hospital/enhancement-building/heimenzu.html)

大学の斜め上からの写真には、赤系の舗装、玄関動線を挟む二つの植栽、東側の石積みの上の金属柵と駐車場表示、その奥のガラスの上屋が写っている。西側の植栽島は低くし、街路側に大きい樹木、建物側に小さい樹木を置いた。東側の石は一つずつ輪郭と出幅を変えた。柵の小さな案内図は収録した棟の輪郭から描いている。[大学のC棟前庭の写真](https://admissions.isct.ac.jp/ja/001/student-life-and-careers/campus-intro/yushima-surugadai)・[橋上からのモデル](qa/clinical.png)・[横断歩道からのモデル近景](qa/clinical-forecourt.jpg)

## 2号館

大学の建物紹介の「Building 2 / 2号館」では、玄関に向かって左に配管が水平に走り、階段の手前で折れ下がる。右には階段に沿った植栽があり、その先に樹木がある。階段は踊り場を含めて立体化し、庇の明るい下面と茶色の縁、庇を支える斜めの方杖、玄関上部の欄間を分けた。建物の北東面に並ぶ三段の窓を、縦桟、欄間、一部の上窓にある丸い部材まで作り分けた。外壁のタイルの目地を現地寸法系のシェーダーで描き、遠景では滑らかに弱めた。[大学による現況の玄関写真](https://www.tmd.ac.jp/cmn/jdp/images/science_tokyo_advantages/img15.jpg)・[旧本館の大学資料](https://www.tmd.ac.jp/outline/introduction/tenji/no1/)・[モデルの玄関](qa/building2.png)

## 寸法と照合範囲

C棟の最高高さ42.6 m、2号館の最高高さ19.1 mと主な屋根面の高さ約16 mはキャンパスの測量データに合わせた。フィンの断面、窓・建具の奥行き、階段の蹴上げ、石積みの個々の形、植栽の高さには、写真上の比率からの推定を含む。ガラス越しに見える床と奥の壁も、外から見た奥行きを表現するための簡略形状である。[建物別の高さと出典](sources.md)

## 庭の西側に見える順天堂医院1号館

屋上庭園からは、道を隔てた順天堂医院の高層部と、緩く湾曲した低い車寄せが見える。東京都の2024年公開点群から、車寄せの屋根を標高約28 m、光庭の底を約46 mと読み取った。高層部は標高約79・83・87 mの屋根と約93 mの塔屋に分けた。太い柱間の九連の窓と窓の奥の暗い帯は順天堂が公開した1993年の竣工写真を参考にした。窓の見込みと車寄せの柱間隔は推定値を使用した。[順天堂の竣工写真](https://goodhealth.juntendo.ac.jp/story/000382.html)・[現在の庭からの眺め](https://admissions.isct.ac.jp/ja/001/student-life-and-careers/campus-intro/yushima-surugadai)・[東京都区部点群データ](https://catalog.data.metro.tokyo.lg.jp/dataset/t000029d0000000024)
