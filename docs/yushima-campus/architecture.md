# 湯島キャンパスの建築外観

湯島地区の大学・病院施設を16個の選択できる建物として収録した。公式案内図で一つの名称を持つD棟は、北の高層部と南の低層部に分けた。平面形と高さに用いた資料と座標系は同じディレクトリの `sources.md` に記載している。[東京科学大学のキャンパス案内図](https://www.isct.ac.jp/ja/001/about/campuses-and-offices/yushima-and-surugadai)

| M&Dタワー | 26階・最高部126 m。神田川に向く広いガラス面の上下で窓の割りと腰壁を変えた。斜めに切り落とした妻壁の小窓、屋上の高低差、中央ボイド、庇と庭園に面した入口を表現した。空中写真・断面図と東京都の点群を照合した。[文科省・大学施設の事例集 pp.11–12](https://www.mext.go.jp/content/1387798_8.pdf)／[竣工時の大学発表](https://www.tmd.ac.jp/cmn/soumu/kouhou/tmdunews/091016.html)／[現行の受験生向け施設写真](https://admissions.isct.ac.jp/ja/001/student-life-and-careers/campus-intro/yushima-surugadai) |

## 病院A棟の南面

病院支援基金の表紙写真では、左上のヘリポートの下に和英の病院名が並び、その下に細い換気スリットと9列×9段の病室窓が見える。南面はこの割付に合わせ、枠、窓台、ガラス、カーテンを外壁から奥へ順に配置した。標章は病院が公開している輪郭に厚みを付け、文字の隙間から外壁が見えるようにした。窓の奥行き、カーテンの開き方、標章の厚みは写真からの推定。近景では建物に隠れた門や病棟のラベルを省く。[病院支援基金の表紙写真](https://www.tmd.ac.jp/dent_hospital/news/support-fund/info.pdf#page=1) · [病院の和英標章](https://www.tmd.ac.jp/medhospital/assets/img/logo.svg) · [指定画角の修正前後と病棟全体](qa/ward-comparison.jpg)

屋根と着陸面の高低差8.03m、着陸帯24.1×20m、B棟への連絡橋の有効幅4mは大学の改修資料による。写真で白い床下に見える柱脚、鉄骨の筋かい、外周の歩廊と、A・B両棟の光庭を立体で表現した。鉄骨断面や各設備の細部寸法は施工写真と点群からの推定。[大学の改修資料](https://www.tmd.ac.jp/archive-tmdu/kouhou/20150129.pdf) · [施工会社の完成写真](https://www.aero.co.jp/2018/05/06/20180506-37/)

窓、柱、ひさし、屋根設備、案内文字・レリーフはメッシュで構成する。M&Dタワーと病棟の窓には、それぞれの位置から3Dモデルの空や周囲の建物を描画して映り込みを作った。

東京都の航空レーザーから読み取れるのは主に屋根と地盤の高さである。応募者向け写真や設計者資料で確認できない裏面の仕上げ、窓一枚ごとの寸法、サッシの奥行き、庇と屋上機器の細部には推定を含む。C棟の渡り廊下は断面で確認できる階を反映し、幅と間柱の数を外形に合わせて近似した。建物内部は対象外としている。
